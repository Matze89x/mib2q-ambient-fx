Helligkeit –

Die Vorschau zeigt die Wunschfarbe. Im Fahrzeug wird sie (bei aktivem „Werksfarben“) auf die nächste Werksfarbe gerundet, dann erst gedimmt.

Kontur: wird vom Design gesteuertFläche: passiv, bleibt manuell im MMI

Was wird gesteuert?

Fahrsimulator

Werte der Vorlage:

1Farbe

Der Farbton dreht sich endlos über das Farbrad, schneller mit dem Tempo (wie „Scroll“).

2Helligkeit

3Bremsen

4Feinschliff

Frei gestreamte Zwischenfarben können auf manchen LED-Streifen flackern. Mit „Runden“ nimmt AmbientFX die nächste Werksfarbe und dimmt erst danach.

Design als Text

Zum Teilen im Chat oder zum Speichern. Der Name steht nicht im Text, er kommt aus dem Namensfeld.
